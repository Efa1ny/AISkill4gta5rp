# Инструкции для ИИ-агентов (GTA 5 RP Suite & Mirror Legislation)

Этот репозиторий содержит модульный комплекс скиллов и инструментов для работы с серверами GTA 5 RP, их форумом (XenForo 2.3) и официальной законодательной базой сервера **Mirror**.

> ⚠️ **Главное правило развертывания**:
> Агенту необходима **вся папка репозитория целиком** (или скачанный ZIP-архив), содержащая подпапки `gta5rp-mirror-legislation/`, `references/` и `scripts/`. Не передавайте этот файл в изоляции без базы законов и скриптов поиска.

---

## 1. Команды вызова плагина в чате (Chat Commands / Triggers)

Когда пользователь вводит в начале сообщения любую из следующих команд:
- **`/mirror-law <запрос>`**
- **`/mirror <запрос>`**
- **`/gta-law <запрос>`**

Или задает вопросы вида:
- *«проанализируй ситуацию по законам Mirror»*
- *«проверь законность задержания / обыска»*
- *«какие статьи УК/ПК нарушены»*
- *«составь иск / определение / постановление»*
- *«найди статью в УК / ПК / СК / ЗОТ»*

**Агент ОБЯЗАН немедленно активировать Модуль 3 ([`gta5rp-mirror-legislation`](./gta5rp-mirror-legislation/SKILL.md))** и следовать протоколу юридического анализа, используя локальную базу `references/laws/` и поисковую утилиту `search_mirror_law.py`.

## 3. Как агенту выполнять поиск по законам (БЕЗ ГАЛЛЮЦИНАЦИЙ)

Никогда не придумывайте статьи и номера законов из памяти. Используйте консольную утилиту поиска:

```powershell
# Точный поиск статьи в конкретном кодексе:
python "gta5rp-mirror-legislation/scripts/search_mirror_law.py" --law УК --article 17.6
python "gta5rp-mirror-legislation/scripts/search_mirror_law.py" --law ПК --article 15.1
python "gta5rp-mirror-legislation/scripts/search_mirror_law.py" --law "взаимодействие" --article 8.1
python "gta5rp-mirror-legislation/scripts/search_mirror_law.py" --law "ордера" --article 2.1

# Полнотекстовый поиск по ключевым словам:
python "gta5rp-mirror-legislation/scripts/search_mirror_law.py" --query "неповиновение"
python "gta5rp-mirror-legislation/scripts/search_mirror_law.py" --precedents --query "LEP-1"
python "gta5rp-mirror-legislation/scripts/search_mirror_law.py" --ooc --query "штурм"
```

## 4. Золотые правила для агента при правовом анализе на сервере Mirror

1. **Приоритет OOC-правил**:
   - При коллизии между IC-законом и OOC-правилами проекта/сервера **всегда побеждают OOC-правила сервера Mirror** (`references/mirror-ooc-overrides-and-precedents.md`).
2. **Прецедент Верховного суда LEP-№1 (от 19.10.2026)**:
   - Неповиновение по **ст. 17.6 УК**: обязательно минимум **2 законных требования** и выжданные **10 секунд** на непрерывной записи!
   - Отказ от оплаты штрафа по **ст. 17.7 п. 3 УК**: обязательна выписка функционального тикета и истечение **20 секунд**.
   - Любые сомнения из-за неполноты записи госслужащего толкуются **в пользу обвиняемого**.
3. **Задержание госслужащих при исполнении (ст. 8 Закона о взаимодействии силовых структур)**:
   - Задерживать госника на месте разрешено **ТОЛЬКО** при нападении, угоне, сбыте оружия, статьях глав 6–10 УК, 12.8 УК или ЗОТ 12.7 УК.
   - За должностные статьи (15.1, 15.6) задерживать госника на месте **ЗАПРЕЩЕНО** (только фиксация и передача дела в Прокуратуру).
4. **Специальные отделы**:
   - Писать кейс-файлы на рейды имеют право **только отделы `DB` (LSPD/LSSD) и `CID` (FIB)**.
   - Патрулировать штат на предмет поиска дезертиров армии имеет право **только военная полиция `MP` National Guard**.
5. **Игровой функционал GTA 5 RP**:
   - Наручники `X`, конвоирование `Z`, выход в наручниках = системный Деморган.
   - В ЗЗ без маски разыскиваемый помечается плашкой `WANTED` — госники по IC сразу знают о розыске.
   - Наркотики `SPUNK`/косяки и оружие в окне обыска не требуют экспертизы.
   - Статус `SP` в жетоне — агент засекречен и не раскрывает имя/паспорт.
   - Боди-камера из `24/7` охватывает сектор 180° от груди.
   - Штрафы оплачиваются на месте, за парковку на **виртуальных парковках** штрафовать и задерживать запрещено (п. 3.17).
   - Автоугон/сутенерка — обязательно до 2 попыток отыгровки `/try`.
